# PIT-003 样式相同不证明字段映射正确

适用：显式layout或别名适配。先核对真实表头/列位置，编号和优先级均居中仍可能填错；不要以样式通过替代语义映射。工具必须核对原label与标准role，错误标签或错列不能通过。缺口明确报告，不能修改原表来消除检查错误。

不适用：据此宣布自动化数据映射或业务断言正确。旧问题由隔离样例复现，错误布局/别名标签/未知Sheet已加入回归；复杂表头仍须实际核对。

新增已复现边界：layout末列遗漏也可能漏掉错误。当前修订核对实际有内容列；遗漏必须报告UNMAPPED_COLUMN，批准排除需理由且只称部分范围。错误列声明和遗漏列是两种不同缺口，均需核对。此修订尚未发布。
