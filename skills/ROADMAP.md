# 技能扩展规划

P0 已实现 testcase-iteration、pytest-generation，维护源在 skills/，发现副本在 .agents/skills/。
P1 defect-analysis：输入失败日志、版本、复现步骤和源码，输出根因假设及证据等级；必须区分测试缺陷、SDK 契约差异、环境与固件，不能仅凭日志判硬件损坏。验收：无日志时不虚构根因，两个版本冲突可追溯。
P1 coverage-review：输入接口目录、Excel、静态测试映射，输出已映射/缺失/未确认；分母来自批准的接口清单。验收：未知分母不输出百分比、重复用例不增加覆盖。
P2 test-report：输入真实 pytest/Allure 结果与环境快照，输出通过、失败、跳过、恢复失败与待确认。结果只写副本。验收：离线语法通过不会转成业务通过，缺失报告不会填零失败。
