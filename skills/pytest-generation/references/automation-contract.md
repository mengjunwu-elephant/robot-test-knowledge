# 自动化测试契约

- 输入 → 前置条件 → 单接口调用 → 类型/结构断言 → 业务值/回读 → 恢复与证据。不能以无异常代替业务通过。
- 生成前检查 API 签名、异常、单位、范围、版本和可信来源；缺失项标为待确认，不能猜 SDK 规则。
- 原 Excel 只读，编辑时产生副本；保留字段、Sheet、ID、格式、公式、分类及报告追溯。分类按既有 test_type，不根据数值重新推断。
- 复用已验证 fixture，不创建连接，不抽出万能 Executor/Adapter；接口初始化与恢复留在当地规则规定的位置。
- 保留 Allure feature/story/step、附件与实际参数日志；恢复失败必须显式记录，不能吞掉。
- 所有等待有超时。正常/边界/异常/状态/恢复维度按契约挑选，不将不适用维度凑成用例。
- 默认采用授权的静态离线校验；compile/AST不等于业务正确。collection需要明确授权并先审查导入副作用，本知识库不运行来源项目collection或设备测试。
