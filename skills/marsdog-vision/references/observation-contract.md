# 视觉直驱 — 观察契约与禁止断言

先明确**可观察对象**，再写预期。不能以「没有报错」代替事件验证。

## 1. 主抓可观察对象

| 对象 | 用途 | 备注 |
| --- | --- | --- |
| Topic `/perception/visual_event` | 是否上报、是否仅 1 条、HOLD 零增量、EXIT 后再现 | 主抓 |
| 调试页 `http://<IP>:8765` | 身份框、identity、tracking_state、骨架/手势等 | 仅断言页面已支持且有依据的字段 |
| 直驱行为（转头/摇尾/靠近等） | 成立触发一次；HOLD/持续不重复 | 行为名以需求/已确认 ACT_* 为准；未拍板写描述性预期 |
| 日志（状态机迁移） | ENTER/HOLD/EXIT 打印 | 常不可观测 → 不作唯一判据 |

## 2. 情绪与其它可观察（可测 / 待确认）

| 对象 | 策略 |
| --- | --- |
| 情绪各维度读数 | 1023 硬测项按可测写；**手段未定** → 标待确认，不假装「一律挂起」，也不无条件标通过 |
| 靠近动机等 | 表内/开发已纳入则写；否则待确认 |
| HOLD 叠情绪细则 | 有依据才硬断言 |
| 陌生人 ALERT/FRIEND | 已确认名与条件可写预期；未确认则待确认，不得只验上报却勾选分支通过 |

## 3. 推荐断言形态（事件行）

- 成立时刻上报：**已确认事件名**或「**待确认**」+ 状态语义（ENTER/TRIGGER），**仅 1 条**。  
- HOLD：无新增同类 Topic + 不重复直驱。  
- EXIT：退出跟踪；**不发结束通知**（若开发已确认）；调试页身份框消失/tracking 停止。  
- 重触发：间隔内不上报；间隔外可再 1 条。  
- 负向身份：不误报主人专属序列。  
- 步骤与预期**同编号**。

消息体字段（identity、bbox、confidence、state 等）：**有契约才写**；样本有而需求未定义的标待确认。

### 3.1 草稿名 vs 已确认名（预期列）

| | 允许 |
| --- | --- |
| 已开发确认 | 预期硬写 `EVT_VISION_*`（或项目约定正式名） |
| 未确认 | 预期「待确认」；草稿名只进备注并标明非正式 |
| 禁止 | 未确认却硬写；已确认与草稿混称为「一律非正式」而与采用正文冲突（除非用户改口） |

## 4. 禁止断言 / 禁止行为

### 4.1 契约与数据

- **猜填**准确率%、时延 ms、容差 ±、帧率、CPU/GPU 上限等无批准基线的数值。  
- 把 **1023 / v7 / v2.2 示例**里**未确认**的预期（含未拍板 `EVT_*`、夹带阈值）直接当契约。  
- 将 **仅草稿**事件名写入预期冒充正式名。  
- **未书面批准**却扩展 Stop/跌倒/仲裁/FOOD/中性等为阻塞用例。  
- 用「情绪无变化」代替「无映射增量 Δ」。  
- 伪造「本轮情绪一律挂起」口径，掩盖 1023 已写硬测。  
- 用「异常输入容错」冒充「崩溃拉起后直驱可用」等**待补**专条。

### 4.2 流程与授权

- 跳过 testcase-iteration 的 Sheet → 测试点 → 方案关口。  
- **未授权**连接真机、SSH、串口，或对知识库任务跑来源项目 collection / 设备测试。  
- 未执行填 Pass；旧实测迁入冒充新版本。  
- 观测未定却勾选情绪「已通过」。

### 4.3 模板与资产

- 擅自删改未批准 Sheet、清空历史实测、覆盖无关旧行。  
- 向技能包或仓库提交**完整业务工作簿**、密钥、现场 IP/账号。

## 5. 环境行为矩阵（摘要）

| 场景类型 | 操作对象 | 可观察（主抓） | 预期 | 禁止副作用 |
| --- | --- | --- | --- | --- |
| 状态型身份/表情/玩具 | 目标稳定 ≥~T_enter | visual_event 一次成立 | 已确认名或「待确认」；HOLD 不重复 | 误报其他身份事件 |
| 瞬时姿态/手势 | 招手、弯腰等 | TRIGGER 一次 | 解除前不连续触发 | 未达条件却上报 |
| 陌生人 | 未注册人 | 事件必报 | 有上报；分支名按确认状态 | 情绪未确认却标分支通过 |
| 情绪硬测 | 主人表情等 | Topic + 情绪读数 | 按可测写；手段待确认则标注 | 无观测却硬判通过 |

## 6. 交付前视觉语义自检（补充）

在 testcase-iteration 结构/格式检查之外，人工抽读：

- [ ] 编号/分区对齐 `MD-VDE-*` 与 A～G（或当次批准的模板）  
- [ ] 事件名：已确认与「待确认」区分清楚；草稿不进预期冒充  
- [ ] 主抓 Topic / 一次上报 / HOLD / EXIT 写清  
- [ ] 情绪：硬测可测写；观测未定有待确认；无「一律挂起」假口径  
- [ ] 扩展分区仅含**已书面批准**范围  
- [ ] 待补洞（低置信、玩具准确率、重启、崩溃拉起等）未假装覆盖  
- [ ] 性能阈值未定处为待确认/实测；无示例契约化、无未授权真机步骤  
- [ ] skills 内无完整业务 CSV/xlsx
