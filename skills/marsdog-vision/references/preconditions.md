# 视觉直驱 — 前置操作模板

只写**执行前必须成立**的状态与启动动作。下列对齐权威采用样本「Marsdog 视觉直驱事件测试用例_1023_Sheet10」（`MD-VDE-*`，模块 A～G）；**无依据的现场 IP、账号、阈值不要写死**。

## 1. 公共启动块（默认复用）

写入「前置条件」开篇（1023 ①～④ 同构）：

1. **启动节点**  
   `ros2 launch marsdog_vision_interaction vision_debug.launch.py web_host:=0.0.0.0`
2. **调试页**  
   `http://<机器狗IP>:8765`（相机 / 骨架 / 身份 / 情绪等以现场页面为准；IP 用占位）
3. **事件监听**  
   `ros2 topic echo /perception/visual_event`
4. **光照与画面**  
   光照 ≥300lux；无强反光；单测时无关人员不入镜（多人条按该用例步骤，不在此偷加范围）
5. **身份注册**（按场景勾选）  
   - 主人：主人已完成人脸注册  
   - 熟悉人：家庭成员已完成人脸注册  
   - 陌生人：无已注册人员在场（或明确仅陌生人入画）

模板已有环境1/环境2 结果列时，不必在每条前置重复「实机/仿真分别执行」。仿真路径未证实前默认真机调试，不臆造独立仿真 Sheet 义务。

## 2. 按场景追加的前置

| 场景类型 | 在公共块上追加 |
| --- | --- |
| 主人 HOLD / EXIT / 重触发 | 已触发主人成立（ENTER→HOLD）；主人正在或刚离开画面（按步骤） |
| 表情类（开心/难过等） | 身份 owner 且 tracking_state=tracking；若本行验情绪：记录触发前情绪基线 |
| 情绪精度类 | 表内若写「调试页/API 可读取情绪精确值」——属**表内自述**；接口未拍板时预期侧标待确认，勿升格为已发布 API 契约 |
| 姿态/手势（招手、弯腰等） | 身份 owner 且 tracking；`pose_event_gate` 等字段以实现/字段解释为准，有依据才写 |
| 陌生人双分支 | 未注册陌生人；分支制造条件以开发确认/表内步骤为准；未确认处标待确认 |
| 玩具 | 约定有效玩具可入视野；清单/距离未拍板处标待确认 |
| 性能/长稳 | 启动日志与资源/内存监控可用；时长与阈值未定则待确认，先具备记录手段 |
| 扩展（Stop/跌倒/仲裁/狗粮/中性等） | **仅当书面批准纳入本轮**时写对应前置；未批准不生成阻塞用例 |

## 3. 距离与站位（有样本依据才写）

1023 常用：

- 正面距相机约 **1.5m** 稳定站立  
- 入画后稳定时长覆盖 **T_enter**（常见约 1.0s；步骤可写「≥2s 留余量」；作硬契约前须有需求/开发确认）  
- EXIT：连续丢失 ≥ **T_exit**（常见约 2.0s）  
- 重触发间隔 **T_retrigger** 常见 3～5s；取定值未拍板时标待确认

禁止：把外部稿夹带的 ±容差、准确率%、端到端 ms 等无需求数值写进前置或预期。

## 4. 清场与无残留

步骤开头建议：

- 画面初始无人 / 无目标身份框  
- `/perception/visual_event` 无该事件残留  
- 需要时先记录情绪基线，再操作

## 5. 不属于用例前置的内容

- 审批、资料查证、版本哈希、技能包安装  
- 未提供的现场默认 IP、账号密码、VPN  
- 「已获得确认执行」等流程语句  

软件/SDK 完整版本放首页或测试需求说明，不塞进每条视觉用例前置。

## 6. 待确认 / 可测标注（备注，非「一律挂起」）

- 观测手段未定：  
  > 【待确认·观测】情绪读数依赖调试页/API；接口未拍板前本断言不作为无条件通过依据。  
- 事件名未确认：  
  > 【待确认·事件名】预期列写「待确认」；草稿 EVT_… 仅追溯。
