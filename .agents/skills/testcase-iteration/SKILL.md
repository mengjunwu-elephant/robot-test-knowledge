# testcase-iteration

读取当前规则技能、接口文档、SDK 版本证据、Excel 原表及对应测试。用 [项目差异参考](references/project-context.md) 识别项目差异，重新验证快照。
先输出输入、预期、前置、恢复与证据缺口；正常/边界/异常/状态维度以实际契约为依据，不发明角度、限位、返回或异常。
新方案提出至少三个收敛问题（范围、可信版本、预期/恢复），待用户确认执行；已确认任务继续执行范围内工作。
制作逐行变更清单，保留 Sheet、字段顺序、ID、test_type、公式与样式。原工作簿只读；获准编辑也先产出副本并比较差异。
每个新增用例映射来源段落和接口；待确认内容不得伪装可执行数据。ROS automation_id 不与 SDK title ID 混用。
按优先级保存方案，更新项目既有方案总文档与唯一交接文档；列出已验证、未验证与下一步。不得调用设备或执行硬件测试。
