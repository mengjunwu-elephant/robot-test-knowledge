# Sheet、测试点与方案确认

三个关口适用于新编写或迭代用例任务；引用已明确批准的同一范围，不重复索要相同批准。用户批准技能升级不等于批准实际项目的全部Sheet或测试点。

1. **Sheet范围确认**：读取原工作簿实际Sheet。逐项说明用途、拟新增/修改/保留/排除、模板映射、环境列、预期依据与缺口。用户选择后记录确认的Sheet、操作及版本。不得默认全选、擅自改名/删除/拆分。范围发生变化时只确认变化部分。
2. **测试点确认**：仅在已确认范围输出独立测试点，标明所属Sheet、验证目的、正常/边界/异常/状态/恢复等适用维度、可信预期来源、优先级、沿用/新增/修改/拟作废和待确认项。先交付可评审的测试点清单，等待用户明确认可；这不是完整方案，也不直接生成Excel。测试点可以使用临时追溯标识，但不擅自改变正式用例ID或加列。
3. **完整方案确认**：依项目“确认执行后才能输出方案”的规则，测试点认可时明确取得“确认执行（输出方案）”，已有针对同一范围的授权可直接引用。然后输出P0/P1/P2方案，包含字段和样式基线、逐Sheet操作、测试点到用例映射、历史证据保护、交付副本、检查及未验证项，保存方案并同步唯一方案总文档。收到针对该方案的“确认执行（生成副本）”后才生成或修改用例副本；未注明阶段时结合上下文记录批准范围。

仅完成阶段所需工作；等待时可以继续只读查证。未知接口预期不能通过确认流程变成已知事实。结束时更新唯一交接及相关规则技能，明确当前关口、确认原话/范围和下一步。
