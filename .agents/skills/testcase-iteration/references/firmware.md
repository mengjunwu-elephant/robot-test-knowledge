# 固件与 Python 库用例
模板：assets/templates/固件测试用例模板_v1.0.xlsx。
接口 Sheet 使用指令序号、功能名称、测试接口、测试目的、优先级、前置条件、步骤、预期及两个环境四列，不能与 SDK 自动化表的 title/expect_data 混用。
先核对协议、单位、参数编码、型号和完整版本；错误码、掉电行为、时间阈值没有依据就待确认。
Python 库场景先指定库路径和版本，静态检查公开方法、参数和返回行为；导入/初始化可能连接串口，本技能只写步骤，不执行。每条测试点写独立目的。库在发送前抛 ValueError 是库行为，不能证明固件会返回 FF；缺少方法不得臆造调用。
响应时间 Sheet 按原字段保留平均、最大最小、中位数、方差、丢包率、错误率、截图。表头中的1000次是模板默认统计口径，真实任务需确认样本数、测量起止与阈值；不同口径先提示冲突。该 Sheet 没有环境列，不自行添加。老化按测试项/前置/脚本逻辑/判定标准/结果/状态/异常回归/证据/备注记录。
模板保留原字段、顺序、两层环境表头与样式；每个环境记录实际结果、执行状态、回归测试记录、测试证据。正式用例无背景填充；有内容的用例区使用细实线全框线（含空结果栏）。描述字段仅同组相邻且内容相同时合并，独立测试项的步骤、预期与结果不跨项合并。无前置填“/”。
优先级：P0 阻断后续测试或严重安全/不可恢复数据损失；P1 核心/高风险；P2 常规/常见异常/边界；P3 低风险辅助。优先级不是缺陷严重程度。
状态仅 Pass、Fail、Blocked、Not Executed、N/A；后两种实际结果留空，失败/阻塞/关键测量附证据。步骤、预期、实际结果按序号对应。实际环境名称须与首页一致。

单接口公共字段、易操作步骤、逐步骤预期和响应时间名称约束见[可直接操作的用例写法](practical-writing.md)。
