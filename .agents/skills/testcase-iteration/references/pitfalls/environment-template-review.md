# PIT-004 环境行为、模板保真与最终复查

适用：同一功能有纯仿真/真机联动等不同运行模式，或新表需要沿用项目模板。

- 测试点评审时逐项列出操作对象、观察对象、预期动作、禁止副作用和判定条件。纯仿真是否要求真机静止、真机联动是否要求模型同步，必须来自需求或用户确认，不能从“仿真/真机”标签猜测。
- 按确认的模板填写。不得为了方便自行重建首页/环境Sheet；逐项对照字段、位置、合并区、样式和环境登记区。不同环境是否共用执行栏取决于已批准的执行记录设计。
- 结构、格式、内容和视觉检查针对最终交付文件。后续删Sheet、改合并区或编辑内容后，重跑受影响的静态检查并复看受影响的视觉区域；说明最终版本实际检查范围。

依据：2026-10-14 用户提供的 Pro450 用例生成对话及其中记录的修订过程。曾出现纯仿真预期混入真机动作、首页偏离通用模板，以及多轮修订后只记录部分静态复核的问题；用户澄清并修正后才形成当前交付。该经验用于加强流程，不代表所有项目采用相同环境或模板。
