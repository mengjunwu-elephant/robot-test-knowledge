# PIT-007 旧表迁移中的合并续行、颜色和空白值

适用：旧用例迁入新模板，尤其有纵向合并、正文底色或工具转换格式时。先按旧 Sheet、行号和编号建立全量对应；读取合并锚点及覆盖行。合并续行的空单元格不等于该用例缺步骤或预期。只有确认整组确实没有依据，才标出具体待确认项。共享步骤或预期的迁移范围须由原表语义和当前批准模板决定；每条用例的编号及执行记录仍独立。

原表正文颜色与目标模板的无填充基线冲突时，列出颜色、区域、已知用途及两种处理的影响，询问是否沿用。未获选择不自动迁入或清除；颜色覆盖合并区时核对整组边界和实际视图，不以单格样式代表整行。

导出后重新读取交付文件，对照原表和模板检查 Sheet、原行映射、合并范围、应为空的区域及新增的 `0`、`/`、“待补充”等占位值。发现异常先查单元格存储值与业务含义，不能把所有数字零当错误。静态统计之外复看受影响区域；报告具体检查范围和无法验证的视觉效果。

依据：2026-10-26 审查“修改 Tuya 测试用例”对话。首次迁移报告 265 条接口，用户指出后补回旧表 10 行；旧表合并续行又被误填“待补充”。用户随后指出灰色局部填充、空白格出现 `0`；执行者报告清除 81 个多余文本零。以上是对话中可见的反馈与处理，未独立核验最终 Tuya 工作簿，不据此证明最终视觉结果或将 Tuya 灰色语义推广到其他项目。
