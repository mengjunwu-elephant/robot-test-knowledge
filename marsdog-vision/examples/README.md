# 样例说明（勿塞入完整业务工作簿）

本目录只放**路径说明与用法**，不内嵌 Marsdog 业务 Excel/CSV 全文。

## 权威采用样本（业务 / Project 侧）

采用表（CSV，便于只读引用）位于 Project store，例如：

`internal/marsdog-inputs/adopted/Marsdog视觉直驱事件测试用例_1023_Sheet10.csv`

合并进 `robot-test-knowledge` 时：**不要**把该业务文件拷进 `skills/` / `.agents/skills/`。仓库 `examples/` 仅保留本 README 类说明即可。

## 样板对齐要点（可学）

| 可学 | 注意 |
| --- | --- |
| 列与分区：`MD-VDE-*`、模块 **A～G**、多列+环境实测块 | 完整 CSV 留在业务侧 |
| 公共前置：launch、`:8765`、`/perception/visual_event`、≥300lux、注册身份 | IP/密钥不进包 |
| 步骤：画外入画、约 1.5m、稳定覆盖 T_enter、清场无残留 | 无依据的 ±/%/ms 不进预期契约 |
| 事件名：表内**已开发确认**可写预期；其余「待确认」 | 草稿与已确认须区分 |
| 情绪：硬测按可测；观测未定标待确认 | 不要学成「一律挂起」 |
| HOLD 零增量、EXIT 不发结束通知、T_retrigger 与 T_enter 隔离 | 「情绪无变化」不可判 |
| 扩展（Stop/跌倒/仲裁/FOOD/中性等） | **须书面批准**才生成；默认只示范经典主路径 |

## 技能内演示句（表达方式，非契约）

前置：视觉调试 launch 已启动；调试页可打开；已 echo `/perception/visual_event`；光照与注册满足场景。  
步骤：1）画面无人且无残留事件。2）主人从画外入画，约 1.5m 正面稳定≥覆盖 T_enter。3）观察 Topic 与调试页。  
预期：1）无残留。2）～3）稳定成立时刻上报（已确认则写 `EVT_VISION_MASTER`，否则「待确认」）（ENTER），仅 1 条；调试页身份与 tracking 符合已确认字段；HOLD 期不重复直驱。  
备注：若名未最终发布，注明确认来源或「待确认」；情绪硬测另见同条/专条，观测未定标待确认。
