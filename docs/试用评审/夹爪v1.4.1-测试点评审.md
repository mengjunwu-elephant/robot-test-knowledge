# 夹爪v1.4.1接口测试点评审

**阅读方式：左列找接口，右侧逐项看对应测试点。无评审编号。**

测试点已获用户确认，副本已交付；尚未执行；全部六个用例Sheet，首页只核对。表内测试点来自现有266条设计目的，复合目的后续需拆成独立判定项。待确认栏用于指出依据缺口，不把现有预期当作已批准合同。

串口和Modbus分别评审，不能因接口同名就认为返回、帧和异常合同相同。当前只编写用例，不开展pytest检查。
