## 串口指令测试结果
处理意向：保留78条追溯记录，复核沿用或修改；复合目的拟拆成独立判定项，不直接变更原ID。

- SER-G01 / P1 / 版本：主版本、次版本分别读回，各自与批准构建信息比较；返回类型和编码单独确认。禁止将第一次读回当成预期基线。对应SER-001、002。
- SER-G02 / P1 / ID：合法ID设置并在新ID读回；旧ID不响应；断电保持各为独立测试点。库层边界1/254及非法0/255按指定库校验另列；设备原始帧非法ID响应独立待协议。测试后如何恢复原ID需明确，不能只写“恢复默认”。对应SER-003至005及相关历史场景。
- SER-G03 / P1 / 波特率：合法索引0至5切换后在对应连接速率通信；非法-1/6属于库校验点。写入响应、读取返回是索引还是波特率值、切换生效时机和恢复路径仍待合同确认，不能填猜值。SER-006的预期空白须补依据。
- SER-G04 / P1 / 位置与速度：位置0/50/100及越界-1/101；移动调用speed的有效范围1至100，单独set_gripper_speed当前校验允许0至100，二者不能混用。边界动作、实际位置、速度显示和恢复分别判定，物理精度/时限待批准依据。
- SER-G05 / P1 / 使能：0/1配置、相应可观察状态、状态切换后可恢复；缺少公开使能查询方法时不得编造get接口。读状态不等价于证明电机使能，需批准观察方法。
- SER-G06 / P2 / P、I、D：三个接口各自覆盖合法写入/读回、0/254边界及-1/255库异常。参数持久化、默认值及控制效果需要独立资料，不从当前实现推出正确合同。
- SER-G07 / P2 / 其他配置：cw/cww的0至16、最小压力0至254、虚位0至100、保护电流100至300是当前指定库的校验范围。各设置/读回、边界、越界和恢复分别成点；0/100保护电流属于该库越界，不能沿用成“合法电流”。这些数值不自动成为固件或物理单位范围。
- SER-G08 / P1 / 绝对运动：绝对位置命令→运动中暂停→位置/状态在批准窗口保持→恢复到原目标；停止后不继续旧目标；队列变化按协议确认。正常位置控制与绝对位置队列场景不要混成一个条件。只比较命令返回不足以验证暂停/停止行为。
- SER-G09 / P2 / IO：输出0/1/2/3组合分别验证输出状态；IO输入控制是否启用、开合位置和屏幕显示单独判定。库写入响应不代替电平测量；有效电平、默认开关、供电条件待资料。
- SER-G10 / P1 / 通信异常：对库层正确响应、短帧、CRC错误、超时分别定义观察结果；指定库的-1/-2/TimeoutError仅作为该版本库行为证据。固件非法命令、非法帧返回FF仍待协议，不与库ValueError合并。
- SER-G11 / P2 / 缺失入口：MoveGripperToAngle、SetModbus保留待确认。指定库缺少同名公开方法，不推定set_abs_gripper_value是等价替代；屏幕手动模式切换只验证切换后的通信，不能验证不存在的SDK设置返回。

## modbus指令功能测试
处理意向：保留78条追溯记录。按上述功能维度分别在Modbus路径复核，禁止复制串口帧规则或返回合同。

- MOD-G01 / P1：两种库的帧构造、CRC字节序和响应解析分别核对；当前源码的串口读11字节与Modbus路径读8字节是实现观察，不把它推广成所有标准Modbus帧的规范。
- MOD-G02 / P1：同名API在Modbus下的读回、ID/波特率切换及恢复分别确认；保留实际接口大小写和两组环境列。
- MOD-G03 / P1：设备非法地址/功能码/数据值的响应，只在取得设备协议后确定；Python发送前的ValueError不是Modbus设备异常响应。
- MOD-G04 / P1：屏幕启用/关闭Modbus后，两种通信路径各自能否读取和控制分别判定；避免同时打开同一串口导致环境干扰被误判为设备行为。
- MOD-G05 / P2：当前4条预期空白的原行定位见结构问题JSON；保持待确认，不能补为笼统“正常/成功”。

## 屏幕按键功能测试
处理意向：保留15条追溯记录；显示、输入控制、动作和默认选项拟分成可独立判定项。UI设计依据未提供时不宣称界面合格。

- UI-G01 / P1 / UI-001、006：首页元素与配置页元素分别对照批准UI设计；配置页预期为空。长按2s是现有设计，按键时长容差仍需确认。
- UI-G02 / P2 / UI-002：position端点显示与current显示分开。现有预期仅覆盖position的0/100，没有current的单位、精度、刷新与基准，需补独立依据。
- UI-G03 / P2 / UI-003、007：速度1/50/100显示与库读回；各波特率连接和默认选择分别判定，默认值不只依据旧用例。
- UI-G04 / P1 / UI-004、005、008：IO控制关闭时不动作、开启时按有效电平动作、屏幕输入指示与开关默认分别判定。电平条件和防抖需资料。
- UI-G05 / P1 / UI-009、010：open、close、release、hold与校零操作分别成点；校零后的基准和提示、退出行为单独判定，不以“不报错”为通过。
- UI-G06 / P1 / UI-011至013：模式选择指示、允许协议路径、禁止协议路径、是否动作分别判定。连接失败需与端口占用/波特率不符区分，禁止路径的失败表现待合同。
- UI-G07 / P2 / UI-014、015：夹爪ID/主次版本与批准基线比较；舵机ID/版本单独依据设备资料，不能使用夹爪版本接口当舵机版本。
