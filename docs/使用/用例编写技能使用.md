# 用例编写技能怎么用
1. 更新到v0.6.0技能：Cursor刷新插件来源，Codex/Work使用正式包更新；开启新对话，选择用例编写与迭代。
2. 提供工作簿与可信接口资料、产品完整版本、功能变化和范围。技能先读取项目已有规则。
3. 先看实际Sheet清单并选择新增/修改/保留/排除范围，不默认全选。
4. 评审单独输出的测试点清单；确认覆盖与预期依据后进入完整方案。
5. 评审完整方案，回复“确认执行”，才生成用例副本。新的范围变化单独确认，已有批准不重复索取。
6. 按团队通用格式与批准项目差异，按字体字号、字段对齐、全边框和换行配方检查；原结构工具负责填写规则，新工具负责直接样式。
7. 检查发现的问题仍需人工语义与视觉评审。执行结果不自动填Pass，不连接设备。

示例：“用例编写与迭代：审查Pro力控夹爪固件v1.4.1工作簿。先列实际Sheet及各自用途，让我选择范围；然后单独输出测试点，确认后再输出完整方案。格式参考已批准的v1.4.1基线，保留原字段和历史证据，不连接设备。”

仓库未发布优化：只读审查默认结构、格式、内容、视觉四项，工具默认team基线按字段识别，不因项目名称跳过。正式v0.6.0尚未包含本次优化；发布后更新才对已安装同事生效。
