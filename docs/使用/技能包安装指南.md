# 大象机器人测试技能包：安装与使用

1. 下载发布页的 robot-test-knowledge-0.6.0.zip，解压整个文件夹。
2. Windows 双击 Install.cmd。需 Python 3.10 或以上；无需管理员权限。它将技能包登记为个人插件来源。
3. 完全退出并重新打开桌面应用。
4. 打开插件目录，选择个人来源，找到“大象机器人测试技能包”，点击安装/启用。来源名称沿用你已有的个人插件目录名称。
5. 打开 elephant-pytest 项目，新建聊天，在技能选择器选择“用例迭代”或“pytest 生成”。ChatGPT 使用 @；Codex CLI/IDE 使用 $。
6. 说：“检查 mycobot_450 的 get_debug_state 用例，先只读审查，不连接机器人。”
7. 审查后再说：“确认执行，依据已确认用例生成测试副本，保留现有 Fixtures 和 Allure。”

若你想先预览安装路径：运行 python install.py。只有 --apply 才写入个人目录。
安装只复制此插件并更新个人 marketplace.json，不写三个原项目，不修改现有技能或 config.toml。已有 marketplace 会合并并保留其他条目，首次更新保留备份；同名外部插件冲突时停止。

卸载：在应用插件目录卸载此插件即可。来源登记及版本文件保留，可再次安装；不自动删除其他内容。
升级：下载新版本后运行新包 Install.cmd，保留旧版本；重启应用后刷新来源并更新/重新安装。版本目录被本地修改时停止。
本包适用于支持本地插件来源的桌面环境，未上架公共插件商店；普通网页不能直接使用本机插件文件。

包内不含原始工作簿、源码项目、日志或本机路径清单。需要当前项目资料才能工作，不包含完整 SDK 契约，也不会执行机器人测试。
官方格式依据：https://developers.openai.com/plugins/build/plugins

维护者：修改 skills 后同步 .agents/skills 副本，运行 scripts/test_package.py 与 build_package.py。插件身份与版本在 plugin.json；新版本更新测试、归档名与 workflow 发布标签，禁止覆盖已发布资产。包内容由白名单构建，不包含来源项目。GitHub Actions 在 Windows/Linux 隔离目录模拟安装；桌面技能选择器的真实显示与调用需要安装后的现场验收。
