# 测试人员日常使用

## 安装与更新

按[安装指南](技能包安装指南.md)安装正式包。Codex/Work运行Update.cmd后刷新个人来源与插件，再开启新对话；Cursor走其来源刷新入口。在线更新遇限流时下载正式Release手动安装。

## 选择任务

- 审查已有用例：选择testcase-iteration，说明工作簿、Sheet范围和资料。已有授权只读检查直接执行，默认结构、格式、内容、视觉四项。
- 编写或迭代用例：选择testcase-iteration，提供版本变化与可信依据，按Sheet、测试点、完整方案逐阶段确认，再生成副本。
- 编写或维护自动化：选择pytest-generation，提供已确认用例及目标接口，明确允许的生成和静态检查范围，不默认运行设备测试。

示例：“审查本项目xxx.xlsx的指定Sheet，按团队通用标准检查；输出四项实际完成范围与问题，不修改Excel、不检查pytest。”

## 核对交付

确认技能版本、检查范围、采用标准、报告及未验证项。样式通过不代表内容正确或设备通过，未执行不填写实际结果。仓库最新修订未发布时，不能认为正式包已包含。

## 团队规则与反馈

跨项目接入使用[接入片段](../../templates/项目接入-AGENTS片段.md)，合并进已有AGENTS，不覆盖文件。反馈提供任务原话、实际版本、结果与最小脱敏示例；维护和发布见[迭代维护](../维护/技能包迭代维护.md)。
