# 使用、维护与实际能力

更新：2026-10-10。正式v0.6.0，仅两项技能。

## 使用入口

安装见[安装指南](技能包安装指南.md)，任务操作见[团队使用步骤](团队使用步骤.md)及[用例编写使用](用例编写技能使用.md)。仓库内.agents/skills与安装的个人插件是不同入口，不能因为打开父目录就假定发现了下级技能。先确认客户端显示技能及版本，项目路径和快照按本机重新核对。

## 能做什么

用例技能读取可信资料、确认Sheet与测试点、编写或迭代Excel副本并检查结构/样式。自动化技能依据确认用例和现有源码生成或维护单接口pytest副本，保护Fixtures、Allure、数据及恢复逻辑。两者由模型读取资料并完成任务，不是脱离项目的一键测试程序。

遗漏、版本变化和预期依据审查属于现有工作流，人工最终确认；不提供独立缺陷、覆盖或报告技能。普通异常分析可直接对话，不必另安装技能。

## 实际验证

已验证文件与镜像一致、固定提交同步、安装更新及白名单打包；v0.6.0跨Windows/Linux校验通过。夹爪266条用例写法和结构获用户验收，仍有10条缺入口及协议/阈值缺口。自动化演示只完成既有副本局部静态修正，不能据此声称所有接口生成与维护都已验收。

语法、映射、样式通过不是业务覆盖完整或设备通过。未执行不能填写实际结果/Pass；报告缺失不能当零失败。硬件执行、collection与导入副作用需要另行确定授权，不由编写任务推定。

## 资料与维护

接口事实留在原项目，公共库projects保留差异索引；旧快照需刷新判断，不能机械替换哈希消除漂移。维护skills并同步.agents/skills，个人cache不可作维护源。流程见[迭代维护](../维护/技能包迭代维护.md)。

固定提交同步工具默认预览，显式apply才写项目；同名拒绝覆盖，lock记录来源和哈希。与Codex/Work正式包更新、Cursor来源刷新分别处理，不混淆版本机制。
