## 更新

下载正式v0.7.0包，Codex/Work登记后刷新并安装/启用插件，开启新对话；Cursor从来源更新后开启新对话。先让助手说明实际加载技能版本，不能仅根据仓库版本判断。

## 首次试用

选择真实非夹爪工作簿，提供批准Sheet范围及可信资料。说：“使用testcase-iteration审查这些Sheet，按团队通用规则检查，不修改Excel、不检查自动化。”

核对是否分别报告结构、格式、内容、视觉范围与结果；字体、边框、对齐是否实际检查；改名或调列是否继续生效；未知字段/冲突是否明确说明；漏项是否自行补齐，不重复要求同范围确认。视觉仅抽样时应明确区域，不声称全量。

## 反馈最少提供

- 使用工具（Codex/Work或Cursor）、实际技能版本。
- 项目类型、Sheet范围、采用标准。
- 发给助手的原话。
- 哪一步遗漏/错误，实际结果及期望结果。
- 相关对话截图、检查报告或最小脱敏样例。

不发送密钥、现场连接配置或敏感日志。用例结果不因审查通过填写Pass。自动化试用另行说明接口与允许操作，不由用例试用授权执行设备测试。
