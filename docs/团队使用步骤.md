# 团队实际操作
维护者：GitHub 添加成员权限；成员提 PR；审核后合并；在 Actions 的 Build robot test skill package 点 Run workflow 发布。
测试人员：到 Releases 下载最新正式 ZIP，完整解压，双击 Install.cmd；在桌面插件来源安装，开启新对话。
跨项目使用：打开目标项目，在技能选择器选择“用例迭代”或“pytest 生成”，写“检查本项目 xxx 接口，先读现有规则，只做离线分析”。
更新：在解压目录双击 Update.cmd，下载最新正式版并登记，刷新/重新安装插件后开启新对话。离线或失败时保留原版本并显示错误。更新入口不会定时自动运行。
所有项目默认遵循：把 templates/项目接入-AGENTS片段.md 合并进每个项目已有 AGENTS.md；调用技能时公共规则已随技能读取。不要覆盖项目原文件。
例子：选择用例迭代后说“检查 elephant-pytest 的 get_debug_state，只读源码和用例，不连接机器人，保留 Excel 字段”。

注意：GitHub API限流时更新入口会报403，直接从Releases手动下载最新包。主分支保护对普通成员生效，管理员仍可应急绕过；初次团队治理由本次确认执行直接建立。
