# 用例编写技能怎么用
1. 安装0.4.1正式包并刷新插件，开启新对话，选择“用例编写与迭代”。
2. 给出目标用例文件和资料，说明产品、新旧完整版本、哪些功能变化、是否只审查。
3. 技能会核对模板和已有规则，询问缺少的依据；有冲突会告诉你两种来源与影响，让你选择。
4. 确定范围后说“确认执行”，产出用例副本和逐项说明。执行结果不自动填写通过。
5. 查看离线检查发现的问题，再做人工评审。本轮不执行设备测试。

可复制的提问：
“用例编写与迭代：检查这个固件用例。版本无功能变化，以我提供的库和协议为依据。逐条看目的、步骤与预期，指出库校验与固件行为的差异，先只审查，不连接设备。”

本包包含三类原始模板；模板说明页的演示Pass不是真实结果。工具只检查结构和部分填充规则，不会确认SDK行为正确。下一轮选择一个实际接口，用它的版本、协议和工作簿试用并逐项验收。
