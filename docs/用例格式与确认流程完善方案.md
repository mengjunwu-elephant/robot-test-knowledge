# 用例格式与确认流程完善方案

2026-10-10，用户已回答格式基线、测试点顺序、Sheet确认三个问题，并回复“确认执行”。本轮批准修改共享技能及校验工具；后续实际用例的Sheet、测试点、执行方案仍分别确认。本轮不编辑原工作簿，不运行原项目pytest或collection。

P0：写入Sheet范围确认、测试点确认、完整方案确认三个独立关口。先读取实际Sheet并列用途、新增/修改/保留/排除，再等待范围选择；按批准Sheet输出测试点、独立预期依据及缺口，等待测试点确认；之后输出完整P0/P1/P2方案并同步方案总文档，等待“确认执行”后生成副本。已有明确批准可引用但不能把本次技能升级批准当成后续全部Sheet或用例的批准。

P1：参考Pro力控夹爪固件v1.4.1工作簿，只读提取格式与来源哈希。正文统一微软雅黑10号，不加粗；编号、功能名称、测试接口、优先级居中，其他正文按参考字段左对齐；全部垂直居中、自动换行。用例网格黑色细线全边框，合并区域保留外框、不跨独立判定项合并结果。表头微软雅黑10号加粗、水平垂直居中、自动换行，边框依参考浅色细线；封面单独保留实际布局。发现Carlito11号混用列为异常，不作为新基线。新增只读样式校验，检查字体字号、加粗、对齐换行、外框、正式正文填充及字段表头；不宣称视觉与语义验收完成。

P2：同步技能镜像、跨客户端更新提示、规则、README、唯一交接、两个插件版本；按新版本0.5.0打包、隔离回归及Windows/LinuxCI后发布。原模板与原工作簿不改。后续试用对象为力控夹爪v1.4.1和elephant-pytest pro_gripper分支；pytest先做离线源码检查，不导入设备模块、不连接设备。

验收：参考哈希不变；发现真实字体混用；回归能发现字体、字号、对齐、换行、缺边框、填充漂移，并正确处理合并区域外框；原有结构检查、安装、更新、同步回归通过；两个技能及镜像一致；用户Cursor实际0.5.0调用另行验收。
