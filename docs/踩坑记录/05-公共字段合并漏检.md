# 公共字段合并漏检（PIT-005）

## 场景与实际表现

2026-10-22 审查用户提供的“生成 IP1000 新版测试用例”对话。首次交付的工作簿在相邻同名“功能名称”处未按已用模板规则合并；用户指出后，执行者补合并 7 处。首次交付前报告了 34 个唯一编号、68 个未执行状态等数据检查，这些检查没有发现漏合并。

## 证据边界与原因

对话记录可证实用户反馈、补改及数据复核；未见最终文件的视觉检查证据。本次没有独立读取仓库外工作簿，因此不能断言最终文件仍有错误。现有技能已规定同组连续相同公共字段合并和最终文件四项检查；可确认的是执行时漏做了合并检查，不能归因于缺少项目业务规则。

## 正确做法与适用范围

新建或迭代用例副本时，按项目批准规则逐组核对公共字段合并及边界；步骤、预期和执行记录逐项独立。合并区补改后，对最终文件复查受影响的结构、格式、内容和视觉，并报告实际范围。具体哪些字段能合并取决于项目模板，不把 IP1000 的分组方式通用化。
