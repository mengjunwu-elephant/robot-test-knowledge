## 新记录流程

提交最小脱敏现象→核对原因及适用范围→提炼任务短参考或已有规则/工具检查→验证→维护者发布。普通成员PR审核、维护者本人例外按仓库规则。无证据的线索标待验证，不进入强制做法；项目契约问题留原项目，只分享流程经验。

每条记录包含场景/现象、证据与原因是否证实、正确做法、验证、适用/不适用范围、修复版本及未决项。过时记录标被替代和新记录位置，不让旧经验覆盖新契约。

技能源短参考在skills对应references/pitfalls中，安装包不含本目录或原截图。短参考使用稳定经验编号；维护记录保留深度证据，技能按当前任务选择，不全量加载历史。
