# PIT-002 夹爪示例被当作适用条件

场景：格式工具和流程最初围绕夹爪配方，可能把其他项目排除在格式审查外。

证据：旧review_format.py固定夹爪配方，用户明确夹爪仅示例；[通用审查方案](../维护/通用用例审查完善方案.md)。Python默认与CLI不一致问题也由隔离样例复现。

原因级别：工具适用范围与审查职责混淆、默认入口不一致已经核实；不能推断所有同事都遇到同一原因。

做法：团队基线按字段含义适配各项目，产品或Sheet名不是开关。CLI与Python默认team，gripper仅显式历史配方。未知字段/项目标准冲突提示选择和未验证，不猜映射。

验证：非夹爪改名/调列、字体异常、未知字段及命令入口回归通过，Python默认统一team；真实项目整体审查仍需试用。

适用：跨项目用例格式；不适用：把夹爪SDK范围、返回码或物理阈值用于其他项目。

修复：团队通用基线纳入正式v0.7.0；经验短参考从v0.8.0随技能分发。
