# PIT-001 漏做格式审查

场景：用户按技能包审查已有用例，助手声称完成审查却自述没运行格式工具。

证据：用户同事截图及[诊断记录](../维护/v0.6.0格式审查遗漏诊断.md)。未取得完整会话、工作簿或报告，不能断言实际运行过哪些工具。

原因级别：规则路由和交付清单缺口已通过源码核对；同事具体模型决策是自述，未独立验证。

做法：完整审查分别完成结构、格式、内容、视觉，报告方法和范围；有条件时实际执行适用工具，工具失败或无法渲染如实列缺口。已授权同范围漏项直接补齐，不重复索取确认。

验证：相关工具回归及四项交付参考已建立；模型完整行为效果仍待同事真实试用，不把工具测试当模型验收。

适用：完整用例审查；不适用：用户明确只要内容、只评审测试点、自动化任务。

修复：规则和审查路由纳入正式v0.7.0；经验短参考从v0.8.0随技能分发。
