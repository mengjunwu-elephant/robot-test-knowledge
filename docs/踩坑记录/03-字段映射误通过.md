# PIT-003 错误字段映射可能误通过

场景：显式layout把编号与优先级交换，两字段均居中，样式仍通过。

证据：[自检记录](../维护/当前优化自检记录.md)的隔离三列样例。旧逻辑返回static_format_passed=true、unresolved=false；原因已复现。

原因：直接信任layout声明，没有核对真实表头。相同对齐无法证明语义映射正确。

做法：布局核对原标签与位置；错误声明报告FORMAT_FIELD。自定义别名分label和role，经批准适配；别名原标签错误仍不通过，未知Sheet拒绝。

验证：test_incorrect_layout_cannot_pass、test_alias_layout_checks_actual_header、test_unknown_layout_sheet_rejected保护错误/别名路径。只读检查不修改原件。

适用：用例格式显式字段布局；不适用：直接据此判断pytest业务数据映射正确。

修复：正式v0.7.0；本次经验短参考未发布。

未决：复杂多层表头仍需当前表布局与具体区域核对，不称任意Excel均已覆盖。
