# Tuya自动化提炼结果

2026-10-12完成提炼；2026-10-13随v0.8.0正式发布。

## 提炼到哪里

技能入口按实际模型路由：data-and-evidence保存分类/参数化/日志证据/恢复与维护差异，sdk-patterns保存查询/普通设置/异常步骤，ros-patterns保存Service/Topic/生命周期边界，generation-acceptance保存逐项交付复核。无新技能或可直接执行的设备模板。

## 核对与未继承内容

16份源文件记录在[来源证据](Tuya自动化提炼来源.json)，其中10份Python源码仅AST解析，无导入或测试执行。源码不等于正确规格；具体SDK返回/异常类型、运动值、端点和现场配置没有搬到公共模板。

抽样ROS查询只做字段存在检查且有pass，设置为门控骨架、缺业务断言和恢复；SDKdebug示例英文Allure与规则不符且恢复只写回。它们作为已观察的实现缺口标明，未推定整个项目都是此情况，也未擅自修原项目。Topic例子的缺省样本/阈值不推广为通用验收值。

## 验证边界

来源文件哈希与本地HEAD作追溯，HEAD不能覆盖未提交文件状态。技能镜像、包内引用、结构及隔离安装验证只证明可分发和读取，不证明生成业务正确。真实接口生成/维护还需按同事项目进行人工及授权验证，未执行硬件测试。

提炼阶段验证：67项完整性/源规则一致性检查、8项包与安装回归（含参考自包含）、2项更新回归、自动化技能结构验证通过；127处本地文档引用存在检查通过。16份来源在完成时哈希仍一致，原项目未写入。后续v0.8.0发布验证见[项目交接](../项目交接文档.md)；同事真实项目生成效果仍待试用。
